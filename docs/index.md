# Game of Life - Documentación

Bienvenido a la documentación del proyecto Game of Life. Este proyecto implementa el famoso juego de Conway's Game of Life utilizando una arquitectura hexagonal y Python.

## Características Principales

- Implementación del juego de la vida con reglas clásicas
- Interfaz gráfica interactiva
- Simulación en tiempo real
- Estadísticas y métricas en tiempo real
- Configuración personalizable
- Estado persistente
